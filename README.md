# 本免 学科試験 予約空きモニター

警視庁の予約サイトの「空き状況カレンダー」を定期的に見に行き、変化を記録・通知します。
**見るだけで、予約はしません。**

- **〜10/2（調査期間）** `MODE = "observe"`：15分ごとに記録するだけ。通知はエラーと毎晩22時のまとめのみ
- **10/2〜（本番）** `MODE = "hunt"`：変化のたびにスマホへ即通知 → 自分で予約

## 0. 最初に確認すること（重要）
卒業証明書番号を入れなくても**空き状況カレンダーまで進めるか**。
番号の入力がカレンダーより前に必要なら、10/2まで調査はできません（本番モードのみ使う）。

## 1. 準備（最初の1回だけ）

1. Python と Playwright を入れる（ターミナルで）
   ```
   pip3 install playwright
   python3 -m playwright install chromium
   ```
2. スマホに通知アプリ「ntfy」を入れる（App Store で「ntfy」）
   - アプリで「+」→ 自分だけの長い名前（例：`menkyo-juno-8k3q9z`）を購読
   - `monitor.py` の `NTFY_TOPIC = "..."` を同じ名前に書き換える
3. 通知テスト：`python3 monitor.py test-notify`
4. カレンダーまでの道順を記録（試験場ごと）
   ```
   python3 monitor.py record koto
   ```
   - ブラウザで空き状況カレンダーが見えるところまでクリック → ターミナルで Enter
   - **予約確定は押さない**
   - 鮫洲・府中も見るなら `record samezu`、`record fuchu`
   - カレンダーが月ごとなら、翌月表示までクリックした版も別名で記録（例：`record koto_next`）
5. 再生テスト：`python3 monitor.py check --now` →「初回スナップショット保存」と出ればOK

## 2. 自動実行（Mac の cron）
`crontab -e` で1行追加（パスは自分のフォルダに）

**調査期間（〜10/2）：15分ごと**
```
*/15 * * * * cd /Users/あなた/menkyo-watch && /usr/bin/python3 monitor.py check >> log.txt 2>&1
```
**本番（10/2〜）：`monitor.py` の `MODE = "hunt"` に変更し、集計結果で決めた間隔に書き換える**

- PC がスリープ中・電源オフ中は動かない。合宿中にPCを置いてくる場合はこの期間の調査はできない
- 同時実行はロックで防止済み

## 3. 集計を見る
```
python3 monitor.py analyze
```
わかること：
- 何時台に変化（キャンセル）が多いか
- 曜日・試験場ごとの差
- 空いた枠が**何日先の受験日か**（当日〜翌日 / 2〜3日後 / …）
- 空いた枠が**何分で埋まったか** → 本番の確認間隔の決め手

生データ：`observations.csv`（全チェック）、`changes.csv`（変化の差分）、`history/`（変化時のカレンダー本文）

○×の自動判定は目安です。`debug/koto_calendar.html` を Claude に渡せば、このサイト専用の正確な読み取りに直せます。

## 注意
- 閲覧のみ、15分間隔が基本。むやみに間隔を短くしないこと
- 予約サイトの利用規約は一度確認
- 取れたら cron の行を消して止める
